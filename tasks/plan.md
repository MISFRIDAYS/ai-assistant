## จุดอ่อนอื่น (ไม่ใช่เรื่องเงินโดยตรง)
- **ความปลอดภัย:** กุญแจเซ็นแอป + รหัส `aibot123` อยู่ในไฟล์ zip (`aibot-app/app/build.gradle.kts`, `aibot.keystore`) ถ้า repo เป็น public ใครก็ปลอมแอปทับได้
- **ความปลอดภัย:** `ENABLE_SHELL=1` เป็นค่าเริ่มต้น + self-heal แก้โค้ดได้ → ผิวโจมตีกว้าง
- **เก็บโค้ดเป็น zip:** ทุกเวอร์ชันอัปโหลด zip ใหม่แล้วลบอันเก่า → ดู diff ไม่ได้, review ไม่ได้, history บวม
- **ไฟล์ขยะ:** `build-1.yml` ที่ root (GitHub ไม่อ่าน), `.github/workflows/ai-assistant-apk-v12.zip`
- **มีเทสต์ ~4,800 บรรทัด แต่ CI ไม่รัน** → build ผ่านทั้งที่โค้ดพัง
- **ผู้ให้บริการ AI 6 เจ้า** (Claude, Gemini, Chutes Cloud, Ollama, Groq, Cloudflare) → โค้ด fallback ซับซ้อน ดูแลยาก
- **ไฟล์ใหญ่เกิน:** `Bridge.kt` 55KB, `Screens.kt` 44KB, `MainActivity.kt` 38KB

## สิ่งที่น่าจะไม่จำเป็น / เกินจำเป็น (ตัดได้ถ้าไม่ได้ใช้)
