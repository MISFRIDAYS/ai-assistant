# 🤖 ผู้ช่วย AI บนมือถือ Huawei (Telegram + Claude)

คุยกับ AI ผ่าน Telegram ถามข้อมูล ค้นเว็บ และ **สั่งงานมือถือ Huawei** ได้ เช่น ดูแบต, หาตำแหน่ง, อ่าน/ส่ง SMS, โทร, ไฟฉาย, ถ่ายรูป, เปิดแอป, ตั้งปลุก, เตือนความจำ

```
คุณ (Telegram ที่ไหนก็ได้) ──► Telegram ──► บอทที่รันใน Termux บนมือถือ Huawei
                                               │
                                               ├─► Claude API (คิด + ค้นเว็บ)
                                               └─► Termux:API (สั่งงานมือถือ)
```

บอทรันบนตัวมือถือเอง ไม่ต้องเช่าเซิร์ฟเวอร์ ไม่ต้องมีโดเมน

## ✅ 0. เช็คก่อนว่ามือถือรองรับไหม

ไปที่ **ตั้งค่า > เกี่ยวกับโทรศัพท์**

| ระบบ | รองรับ |
|---|---|
| EMUI (ทุกเวอร์ชันที่เป็น Android 7+) | ✅ |
| HarmonyOS 2.x / 3.x / 4.x | ✅ |

## 📲 1. ติดตั้งแอป 3 ตัว (จาก F-Droid เท่านั้น)

Huawei ไม่มี Google Play และ Termux บน Play Store ก็เก่าแล้ว ให้ใช้ F-Droid:

1. เปิดเบราว์เซอร์ไปที่ **https://f-droid.org** → ดาวน์โหลดและติดตั้ง F-Droid
2. ใน F-Droid ค้นหาและติดตั้ง:
   - **Termux**
   - **Termux:API**
   - **Termux:Boot** (ให้บอทเริ่มเองตอนเปิดเครื่อง)

> ⚠️ ทั้ง 3 ตัวต้องมาจากแหล่งเดียวกัน (F-Droid ทั้งหมด) ไม่งั้นจะใช้ด้วยกันไม่ได้
> เปิดแอป **Termux:Boot** หนึ่งครั้งหลังติดตั้ง

## ⚙️ 2. ตั้งค่ามือถือ Huawei (สำคัญมาก ไม่งั้นบอทจะโดนปิดเอง)

Huawei ปิดแอปเบื้องหลังเก่งมาก ต้องตั้งค่าดังนี้:

1. **ตั้งค่า > แบตเตอรี่ > การเปิดแอป (App launch)**
   → หา Termux, Termux:API, Termux:Boot → ปิด "จัดการอัตโนมัติ" → เปิดทั้ง 3 สวิตช์ (เปิดอัตโนมัติ / เปิดรอง / ทำงานเบื้องหลัง)
2. **ตั้งค่า > แอป > Termux > แบตเตอรี่** → ปิดการปรับแบตให้เหมาะสม / อนุญาตทำงานเบื้องหลัง
3. เปิดหน้าแอปล่าสุด (Recent apps) → ปัดการ์ด Termux ลง → กด 🔒 ล็อกไว้
4. **ตั้งค่า > แอป > Termux:API > สิทธิ์** → อนุญาต: SMS, โทรศัพท์, รายชื่อ, ตำแหน่ง, กล้อง, ประวัติการโทร
5. (ถ้าอยากให้อ่านการแจ้งเตือน LINE ฯลฯ ได้) **ตั้งค่า > การแจ้งเตือน > การเข้าถึงการแจ้งเตือน** → เปิดให้ Termux:API
6. (ถ้าอยากให้เปิดแอป/ตั้งปลุกได้) **ตั้งค่า > แอป > Termux > แสดงทับแอปอื่น** → อนุญาต
7. (ถ้าอยากปรับความสว่างได้) **Termux:API > แก้ไขการตั้งค่าระบบ** → อนุญาต

## 🤖 3. สร้างบอท Telegram

1. ใน Telegram ค้นหา **@BotFather** → พิมพ์ `/newbot`
2. ตั้งชื่อบอท และ username (ต้องลงท้ายด้วย `bot` เช่น `my_huawei_ai_bot`)
3. จะได้ **Token** หน้าตาแบบ `123456789:AAH...` → เก็บไว้

## 🔑 4. ขอ Claude API key

1. ไปที่ **https://console.anthropic.com** → สมัคร/เข้าสู่ระบบ
2. เติมเครดิตในเมนู Billing (ขั้นต่ำ ~5 USD)
3. เมนู **API Keys > Create Key** → ได้ key ขึ้นต้นด้วย `sk-ant-...` → เก็บไว้

## 📦 5. ติดตั้งบอทลงมือถือ

1. คัดลอกไฟล์ `huawei-ai-bot.zip` ไปไว้ในโฟลเดอร์ **Download** ของมือถือ
2. เปิด Termux แล้วพิมพ์ทีละบรรทัด:

```bash
termux-setup-storage          # กดอนุญาตให้เข้าถึงไฟล์
pkg install -y unzip
cd ~
unzip ~/storage/downloads/huawei-ai-bot.zip
cd huawei-ai-bot
bash install.sh               # รอสักพัก ถ้าถามให้กด y / Enter
```

3. ใส่ค่าตั้งค่า:

```bash
nano .env
```

ใส่ `TELEGRAM_BOT_TOKEN=` และ `ANTHROPIC_API_KEY=` ที่ได้มา → กด `Ctrl+O` `Enter` (บันทึก) → `Ctrl+X` (ออก)
(ปุ่ม Ctrl อยู่แถบปุ่มพิเศษด้านบนคีย์บอร์ดของ Termux)

4. เริ่มบอท:

```bash
./start.sh
```

5. เปิด Telegram ไปหาบอทของคุณ → ส่ง `/id` → จะได้เลข ID เช่น `123456789`
6. ใน Termux กด `Ctrl+C` เพื่อหยุดบอท → `nano .env` → ใส่ `ALLOWED_USER_IDS=123456789` → บันทึก → `./start.sh` อีกครั้ง

🎉 เสร็จแล้ว! ลองพิมพ์คุยกับบอทได้เลย

> ปิดหน้าจอได้ บอทยังทำงานต่อ (มี wake-lock) และถ้ารีสตาร์ทมือถือ Termux:Boot จะเปิดบอทให้เอง

## 📱 ควบคุมหน้าจอ (ADB) — เปิดทุกแอป, พิมพ์แชทให้, รับสาย

ฟีเจอร์นี้ให้ AI "เห็น" หน้าจอ แตะ ปัด และพิมพ์ได้เหมือนคนใช้ ทำผ่าน **การดีบักแบบไร้สาย (Wireless debugging)** ที่เชื่อมเข้าเครื่องตัวเอง (ไม่ต้อง root ไม่ต้องใช้คอม)

### ตั้งค่าครั้งเดียว

1. **เปิดโหมดนักพัฒนา:** ตั้งค่า > เกี่ยวกับแท็บเล็ต > แตะ **หมายเลขบิลด์ (Build number)** 7 ครั้ง
2. **ตั้งค่า > ระบบและการอัปเดต > ตัวเลือกนักพัฒนา** → เปิด **การดีบัก USB** และ **การดีบักแบบไร้สาย** (ต้องต่อ Wi-Fi อยู่)
3. ติดตั้งเครื่องมือใน Termux: `pkg install -y android-tools python-pillow`
4. **แบ่งจอ** เปิด ตั้งค่า (หน้าการดีบักแบบไร้สาย) คู่กับ Termux
5. ในหน้าการดีบักแบบไร้สาย กด **จับคู่อุปกรณ์ด้วยรหัสจับคู่** จะเห็น `IP:พอร์ต` และรหัส 6 หลัก แล้วพิมพ์ใน Termux (ใช้พอร์ตและรหัสจากหน้าต่างนั้น):
   ```
   adb pair 127.0.0.1:พอร์ตจับคู่ รหัส6หลัก
   ```
   ต้องขึ้นว่า `Successfully paired`
6. ดูที่หน้าการดีบักแบบไร้สาย ตรง **ที่อยู่ IP และพอร์ต** (พอร์ตนี้ต่างจากพอร์ตจับคู่) แล้วพิมพ์:
   ```
   adb connect 127.0.0.1:พอร์ต
   adb devices
   ```
   ต้องเห็นบรรทัด `127.0.0.1:xxxxx  device`
7. ทดสอบ: `adb shell input keyevent 3` → หน้าจอต้องกลับไปหน้าโฮม
8. รันบอทใหม่ `./start.sh`

### หลังรีสตาร์ทเครื่อง / เปลี่ยน Wi-Fi

การดีบักแบบไร้สายมักปิดเองและพอร์ตเปลี่ยน → เปิดสวิตช์ใหม่ แล้วพิมพ์บอกบอทใน Telegram เช่น `เชื่อม adb พอร์ต 41235` (ไม่ต้องจับคู่ใหม่) หรือบอทอาจหาพอร์ตเจอเอง

### ตัวอย่างคำสั่ง

| พิมพ์ | บอททำอะไร |
|---|---|
| เปิดแอป Shopee / เปิด TikTok | เปิดได้ทุกแอปในเครื่อง |
| มีแอปอะไรในเครื่องบ้าง | แสดงรายชื่อแอปทั้งหมด |
| ส่ง LINE หาแม่ว่าเดี๋ยวกลับบ้าน | เปิด LINE → หาห้องแม่ → **ขออนุญาต** → พิมพ์ → กดส่ง |
| ตอบ Messenger ล่าสุดว่า โอเคครับ | เปิดแชท → พิมพ์ → ส่ง |
| รับสาย / วางสาย | รับหรือวางสายที่เรียกเข้า (สาย LINE จะดูจอแล้วกดปุ่มรับให้) |
| ตอนนี้หน้าจอเป็นยังไง ส่งภาพมาดู | ส่งภาพหน้าจอมาให้ |
| เลื่อนลง / กดย้อนกลับ / กลับหน้าโฮม | ควบคุมหน้าจอ |

### ข้อจำกัด
- หน้าจอต้อง**ปลดล็อกอยู่** ถ้าตั้งรหัสล็อกไว้ บอทปลดให้ไม่ได้ (ตั้ง "ระยะเวลาก่อนล็อกหน้าจอ" ให้นานขึ้นช่วยได้)
- ทำงานทีละขั้น (ดูจอ → แตะ → ดูจออีกครั้ง) งานแชทหนึ่งครั้งอาจใช้ 15–40 วินาที และเปลือง token มากกว่าคำสั่งปกติ
- ทุกครั้งที่จะ **พิมพ์ข้อความลงแอป** บอทจะขออนุญาตก่อน ✅ (กันส่งผิดคน)
- แอปธนาคาร/บางแอปบล็อกการอ่านหน้าจอ บอทจะทำในแอปพวกนั้นไม่ได้ (และไม่ควรให้ทำ)
- ถ้าแท็บเล็ตเป็นรุ่น Wi-Fi ไม่มีซิม "รับสาย" จะใช้กับสาย LINE/Messenger/WhatsApp ได้ ส่วนสายโทรศัพท์ปกติไม่มี

## 🎤 ผู้ช่วยเสียง — พูด "สวัสดีผู้ช่วย" ได้เลย

ใช้ **Groq** (ฟรี) แปลงเสียงเป็นข้อความ, **Google TTS** พูดภาษาไทย

### ตั้งค่า
1. สมัคร **https://console.groq.com** → **API Keys** → Create → คัดลอก key (`gsk_...`)
2. ใน Termux:
   ```
   cd ~/huawei-ai-bot
   bash setup_voice.sh          # หรือ bash setup_voice.sh --boot ให้เริ่มเองตอนเปิดเครื่อง
   nano .env                    # ใส่ GROQ_API_KEY=gsk_...
   python voice_chat.py --test  # ทดสอบไมค์ เห็นแถบ █ ขยับตามเสียงพูด = โหมดเรียลไทม์ใช้ได้
   ```
3. เริ่มผู้ช่วย: `python voice_chat.py --wake` (หรือกดปุ่ม **เปิดผู้ช่วยเสียง** ใน widget)

### วิธีใช้
- พูด **"สวัสดีผู้ช่วย เปิดยูทูป"** → ทำทันที
- หรือพูด **"สวัสดีผู้ช่วย"** → ตอบ "ครับ" → แล้วค่อยพูดคำสั่ง
- ตอบเสร็จแล้วถามต่อได้เลยภายใน 8 วินาที ไม่ต้องเรียกชื่อซ้ำ / พูด "พอแล้ว" = จบ
- **พูดแทรกได้:** ระหว่าง AI พูด พูดคำสั่งใหม่ได้เลย เช่น "โอเค งั้นเปิดไฟฉายแทน" → หยุดพูดทันทีแล้วทำคำสั่งใหม่
  (ใช้หูฟัง/ลำโพงบลูทูธจะแทรกได้แม่นที่สุด เพราะไมค์ไม่ได้ยินเสียงลำโพงตัวเอง)
- ปิดผู้ช่วย: ปุ่ม **ปิดผู้ช่วยเสียง** หรือ `pkill -f voice_chat.py`

### ทำไมเร็วขึ้น
- ไมค์ฟังต่อเนื่อง รู้เองว่าพูดจบเมื่อเงียบ 0.7 วินาที (ไม่ต้องรอครบเวลา)
- AI ตอบแบบสตรีม เริ่มพูดประโยคแรกทันทีที่ AI พิมพ์ได้ ไม่ต้องรอคำตอบทั้งหมด
- สร้างเสียงประโยคถัดไปไว้ล่วงหน้าระหว่างพูด

### ปรับแต่ง (.env)
| ค่า | ความหมาย |
|---|---|
| `TTS_VOICE=th-TH-NiwatNeural` | เสียงผู้ชาย / `th-TH-PremwadeeNeural` เสียงผู้หญิง |
| `TTS_RATE=+10%` | ความเร็วพูด (เช่น `+20%` เร็วขึ้น, `-10%` ช้าลง) |
| `QUICK_COMMANDS=1` | คำสั่งง่าย (เปิดแอป/ไฟฉาย/แบต/กี่โมง) ทำทันทีไม่ต้องรอ AI |
| `WAKE_WORDS=สวัสดีผู้ช่วย,ผู้ช่วย` | คำปลุก |
| `VAD_END_SILENCE=0.7` | เงียบกี่วินาทีถือว่าพูดจบ (ลดเหลือ 0.5 = เร็วขึ้น แต่อาจตัดก่อนพูดจบ) |
| `VAD_MIN_RMS=350` | ความไวไมค์ (ห้องเสียงดังให้เพิ่มเป็น 600–1000) |
| `FOLLOWUP_SECONDS=8` | หลังตอบ รอฟังคำถามต่อกี่วินาที |
| `BARGE_IN=1` | พูดแทรกตอน AI กำลังพูดได้ (0 = ปิด) |
| `BARGE_IN_FACTOR=2.5` | พูดแทรกต้องดังกว่าเสียงลำโพงกี่เท่า (แทรกยาก → ลดเป็น 1.8 / หยุดเองบ่อย → เพิ่มเป็น 3.5) |

### ข้อจำกัด
- ระบบลองโหมดฟังตามลำดับ: **เรียลไทม์ (PulseAudio)** → **เรียลไทม์ (AMR สตรีม)** → **สำรอง (อัดทีละ 2 วินาที — ช้า)**
- ตรวจว่าทำไมไม่ได้โหมดเรียลไทม์: `python audio_stream.py`

## ใช้คอมที่บ้านเป็นสมอง (Ollama) — ฟรี ไม่จำกัด เครื่องมือครบ

ออกแบบสำหรับคอมที่มีการ์ดจอ 16GB (เช่น RTX 5060 Ti) ใช้โมเดล `qwen3.5:9b`

**บนคอม (Windows) — ทำครั้งเดียว**
1. ดับเบิลคลิก `windows/ติดตั้งOllama.bat` → กด Yes ตอนขอสิทธิ์ Administrator
2. รอโหลดโมเดล (~6.6GB) จบ สคริปต์จะแสดง **IP ของคอม**
3. แนะนำ: จอง IP ให้คอมในหน้าตั้งค่าเราเตอร์ (DHCP reservation) ไม่ให้ IP เปลี่ยน

**บนแท็บเล็ต (Termux)**
```
cd ~/huawei-ai-bot && bash set_ollama.sh 100.x.x.x 192.168.1.50   # ใส่ IP ตามที่คอมแสดง (Tailscale + Wi-Fi บ้าน)
bash start_all.sh
```

**พกแท็บเล็ตออกนอกบ้าน (Tailscale — ฟรี)**: ตัวติดตั้งบนคอมลง Tailscale ให้แล้ว
บนแท็บเล็ตติดตั้งแอป Tailscale (F-Droid) ล็อกอินบัญชีเดียวกัน กดเชื่อมต่อ และแนะนำเปิด Always-on VPN
บอทจะลองที่อยู่ตามลำดับเอง: ข้างนอกใช้ Tailscale · ในบ้านถ้า Tailscale ปิดก็ใช้ Wi-Fi บ้านแทน

- คอมปิด/หลับ → บอทสลับไปใช้ Claude ให้เองอัตโนมัติ แล้วลองคอมใหม่ทุก 3 นาที
- ค้นเว็บ: ใช้ Gemini (ถ้ามีคีย์) ถ้าโควตาหมดจะใช้ DuckDuckGo ฟรีแทน
- ดูสถานะคอม: ส่ง `/status` ในแชทบอท
- เปลี่ยนโมเดล: `ollama pull <ชื่อ>` บนคอม แล้วแก้ `OLLAMA_MODEL=` ใน `.env`
- กลับไปใช้ Claude: `sed -i 's/^LLM_PROVIDER=.*/LLM_PROVIDER=claude/' .env` แล้วรีสตาร์ท
